## 3. 我们处理哪些信息

### 3.1 第三方登录与账户资料

GitHub、Microsoft、Google 可以用于 Nexa 登录及关联登录身份。根据你的选择，我们处理提供商名称、稳定账户标识、返回的昵称或基本资料、邮箱及关联时间，并保存 Nexa 内部用户 ID、公开用户 ID、显示名和账户角色。不会仅凭相同邮箱自动合并不同 Nexa 账户。

当前普通登录请求的权限为 GitHub `read:user user:email`，Microsoft `openid profile email User.Read`，Google `openid profile email`。我们不接收这些第三方账户的密码。你可以解除登录身份关联，但当前系统要求至少保留一个第三方登录身份。

### 3.2 密码、两步验证和恢复方式

你主动设置 Nexa 密码时，我们保存加盐密码哈希，不保存明文密码。密码登录需要再通过已注册的 passkey、验证器应用或未使用恢复码完成两步验证。

使用 passkey 时，我们保存凭据 ID、公钥、算法、签名计数、你设置的名称及创建、使用时间。私钥和用于解锁凭据的设备生物识别数据由你的设备或凭据服务处理，不发送给 Nexa。

使用验证器应用时，我们保存该设备名称、TOTP 密钥、确认时间和防重复验证状态。生产配置使用服务端密钥加密 TOTP 密钥。添加验证器时，密钥及二维码内容会提供给你的浏览器以便录入验证器。

恢复码验证使用哈希；为支持稍后查看未使用的恢复码，生产配置还保存加密的可恢复副本。再次查看、生成或移除敏感验证方式需要有效账户会话；已设置密码的账户还需复核当前密码。未设置密码时，当前会话本身是授权依据。查看行为记录到安全审计，恢复码每个只能使用一次。重新生成会使旧的未使用恢复码失效。

登录挑战约 5 分钟有效，未确认的验证器注册约 15 分钟有效。这些数据用于验证、避免重放和限制暴力尝试，不用于广告或第三方画像。

### 3.3 会话与安全信息

我们处理会话凭据的哈希、会话范围、创建与到期时间、OAuth state / nonce、登录和绑定结果、限流状态及必要审计记录。限流可以使用账户标识或 IP 的哈希；网络边缘处理请求时仍会接触 IP 和连接信息。

| Cookie | 用途 | 有效期 |
| --- | --- | ---: |
| `nexa_console` | 普通账户会话 | 最长约 24 小时 |
| `nexa_staff` | 内部运营会话 | 最长约 1 小时 |
| `nexa_oauth_state` | 第三方登录防伪造与重放 | 约 10 分钟 |
| `nexa_link_afdian` | 爱发电关联防伪造与重放，仅在发起关联时设置 | 约 10 分钟 |

生产 Cookie 使用 HttpOnly、Secure、SameSite 等属性。网页的短期 API 令牌保留于页面内存，不写入主题偏好或其他持久浏览器存储。退出当前范围的账户会撤销该范围的会话。

### 3.4 可选 Microsoft / Minecraft 关联

普通 Microsoft 登录不请求 Xbox 或离线游戏权限。你主动选择关联 Microsoft 时，授权请求可额外包含 `XboxLive.signin offline_access`，用于查询 Minecraft 拥有状况、档案 ID、档案名和最近检查结果。

获得可用刷新令牌且生产加密密钥已配置时，我们以 AES-GCM 加密保存 Microsoft 刷新令牌，用于之后在你授权请求时取得短期 Xbox / Minecraft 令牌、更新档案。未配置加密密钥时不保存该刷新令牌。用于查询的短期 Xbox / Minecraft 令牌不作为档案记录持久保存；派生出的 Minecraft 访问令牌仅返回给发起授权请求的客户端，不写入普通日志。

该功能需要 Microsoft、Xbox 和 Minecraft 服务参与，它们按自己的规则处理授权、拥有状况和令牌。解除 Microsoft 关联或最终注销账户后，Nexa 删除保存的游戏档案和刷新令牌；你也可以在 Microsoft 侧撤销授权。游戏拥有状况与 Nexa 账户等级相互独立。

### 3.5 社区账号关联

**爱发电**：关联接口使用官方 OAuth 的 `basic` 权限。可用性以页面实际开放状态为准。你主动授权时，我们处理授权结果中的用户 ID、可选私有用户 ID、可选昵称，以及关联与最近检查时间。私有标识用于 Nexa 内部账户关联，不作为公开用户资料展示。我们不要求你提供爱发电密码，也不把社区关联用于 Nexa 登录或账户恢复。

OAuth 授权码用于完成一次交换，绑定状态绑定当前 Nexa 会话、约 10 分钟有效且只能使用一次。我们不为此持久保存平台访问令牌。此授权不提供订单、付款金额或捐赠查询能力；关联成功不会自动授予捐赠铭牌。解除关联删除该映射和未完成授权状态。

**Bilibili**：绑定当前暂未开放。当前公开资料读取仅用于接口可用性验证，未把测试 UID 作为 Nexa 账户绑定，也未为用户创建签名挑战记录。

拟定签名核验方案是在你主动输入 UID 后读取公开的 UID、昵称、头像、签名、等级与粉丝数，以确认账号及控制权。拟定流程为确认资料、三选一签名、由你修改 B站个人签名、发起验证；有效期拟为 15 分钟、最多 5 次验证，只有选中候选有效，重建挑战或更换 UID 会撤销旧项。签名属于绑定当前 Nexa 账户的验证码，**临时公开它可能让他人知道你正在关联该 B站账号**；不要使用别人提供的绑定签名，成功后可恢复原签名。

拟定核验会绕过 Nexa 自己的资料缓存，但不能保证 B站立即刷新；未匹配、限流、响应无效或读取失败都不得判定成功。所有权证明与后续公开资料同步分别处理，资料同步不会替代所有权证明。词库人工审校与生产接口验证通过后才会开放，并提供实际启用时的数据范围、保留规则与选择。我们不收集 Bilibili Cookie、SESSDATA，不模拟扫码登录，不要求开放私人投稿、消息或账户密码。

### 3.6 账户等级、活动与铭牌

账户概览处理当前等级、累计经验、下一等级条件及你选择的显示铭牌。可关联账户的启动器活动与第 4 条的匿名技术遥测不同。

启动器活动接口当前仅预留，不包含启动器客户端接入。接入后须同时验证受信任 mTLS 客户端证书和当前 Nexa 登录凭据，处理账户 ID、事件 UUID、事件类型、服务端接收时间、证书指纹、经验结果、在线累计、每日活动与连续启动记录。客户端不能申报他人的用户 ID、经验数值或时间；同一事件不重复计算，多设备不叠加在线时间。证书指纹用于接口可信校验和活动状态协调，不是普通匿名遥测中的稳定设备 ID。

接入后，经验来源为每天登录启动器 20 Exp、每天首次启动 Minecraft 30 Exp、游戏在线每分钟 1 Exp、启动器在线每 5 分钟 1 Exp；每天合计最多 500 Exp，日期按北京时间（Asia/Shanghai）。在线时间使用有效心跳估算，断网间隔不补记。Lv0 升 Lv1 需要在当前账户登录期间确认一次游戏启动；Lv2～Lv7 的累计门槛为 2k、5k、10k、20k、50k、100k。匿名遥测不发放经验，也不会被反向合并为账户活动。

铭牌处理来源如下：

- **Lv-1**：当前网站管理员状态，权限撤销后不再允许替代等级显示。
- **LvMC**：有效每日游戏启动记录中曾连续 100 天的成就。
- **Lv∞**：Lv7、有效 MC 在线至少 100 小时及通过 ∞ 答题；题库未开放，当前不授予。
- **b站来的**与**小黄标**：B站 Lv6、粉丝达到 100 万的核验结果；当前由管理员依据来源账号与证据核验。
- **我喜欢你**：向 Nexa 无偿捐赠累计严格超过人民币 1,000 元的人工核验结果。订阅和购买不作为无偿捐赠，爱发电 OAuth 本身不提供付款证明。

核验记录包含铭牌类型、核验数值、来源账号或记录编号、必要证据说明、审核人和时间；管理员不能审核自己的资格。请只提供与核验直接有关的材料，不在证据中填入密码、Cookie、完整银行卡信息或无关第三人资料。账户可选择已经获得且允许替代等级的铭牌；替代显示不改变实际等级和经验。未来公开展示会明确说明范围，内部证据不会因获得铭牌而自动公开。

### 3.7 资源、云功能、订阅和支持

当资源功能实际开放并由你提交时，我们处理名称、说明、图标、类别、版本、许可证、兼容信息、权限、依赖、上传文件、哈希、签名、扫描与审核结果、发布和撤销状态。草稿或非公开审核材料不会仅因上传而公开。

当云存储实际开放时，可处理你主动上传的文件及元数据、使用量、配额、同步和删除状态；不会为未来计划提前读取本地文件。

订阅记录包括 Paddle 客户标识与 Nexa 账户关联、必要邮箱、订阅及价格标识、状态、取消安排、交易标识、金额、币种和时间。当前 Paddle 接入是 sandbox 测试环境，测试记录不代表真实付款。实际购买开放后，完整银行卡等付款凭据由付款服务商处理，Nexa 不保存完整银行卡信息。客户门户使用短期会话 URL，不作为业务记录持久保存。

工单、举报、申诉和你联系支持时，我们处理你提供的联系信息、标题、说明、必要附件、订单或核验材料、处理状态和通信记录。公开资源资料或发布者信息可以按你的发布选择向其他用户展示。

## 4. Nexa Desktop 技术遥测

客户端技术遥测仍使用分级协议。必要事件包括 `app.started`、`app.failure`、`update.checked`、`rollout.checked`，字段限制为版本、操作系统、CPU 架构、结果和事件时间等低基数技术信息。

该普通遥测协议不主动附加 Nexa 账户 ID、稳定设备或安装 ID、Minecraft 用户名、本地路径或完整自由文本日志。Cloudflare 在处理网络连接和限流时仍可能接触 IP 等网络层信息，不能据此承诺所有网络层数据均匿名。

诊断遥测根据对应客户端版本的设置与测试参与规则启用。稳定版本可按设置控制；预发布版本可把有限诊断信息作为测试参与条件，具体以该版本提示为准。

诊断可包括游戏、任务、功能类别和网络耗时，内存、CPU、JVM 启动与工作集、Java 主版本、classpath 数量、heap 配置、渲染与模拟距离、FPS 与图形设置、MC 和 Loader 版本、有限 Mod ID / 版本 / 依赖信息，以及符号化异常类型和有限堆栈帧。每次运行使用随机 run ID 关联同次样本，不作为稳定设备身份。完整自由文本错误日志不作为普通遥测上传。

这些数据用于版本故障、性能、兼容性和更新分析，不能用于证明某个 Nexa 账户完成了等级任务。你主动提交的支持日志则按第 3.7 条处理。

## 5. 处理目的和依据

我们为你主动请求的账户登录、安全验证、资料关联、资源交付、订阅管理、等级与铭牌显示处理直接必要的数据；为防止重放、暴力尝试、伪造活动、账户接管和恶意内容进行必要安全处理；为诊断版本问题进行上述有限遥测；为支持、退款、投诉和争议处理必要记录。

具体处理依据随功能及适用法律确定，包括履行你作为一方当事人的合同所必需、适用法定义务或依法取得的有效同意。公开资料并不意味着可以不受限制地加工、共享或另作他用。需要以同意为依据或需要单独同意的处理，不由服务条款接受或本政策知悉回执替代。

拒绝可选 Microsoft 游戏权限、爱发电关联、未来 B站绑定或铭牌人工核验，不影响使用不依赖该功能的服务；对应档案、绑定或铭牌功能可能无法提供。没有有效账户验证时不能使用需要确认账户身份的功能。

## 6. Cookie、浏览器偏好与类似技术

核心 Cookie 用于登录、授权安全和会话。主题选择使用浏览器本地存储 `nexa:theme`，保存“跟随系统 / 浅色 / 深色”之一，直到你改变选择或清除浏览器存储；它不包含账户令牌，不同步到账户数据库、不作为追踪标识。跟随系统时，网页读取浏览器提供的系统颜色偏好以决定界面显示。

我们不把继续浏览视为对未来分析、营销、跨站追踪或非必要 Cookie 的同意。如果引入这些功能，将先提供适用的告知、选择和撤回方式。

## 7. 服务商和信息接收方

### 7.1 Cloudflare

当前 Web、API、Auth 分别使用 Cloudflare Workers；账户、身份、安全、接受记录、关联与等级保存在 Auth 的 D1，资源目录、工单、订阅镜像和遥测保存在 API 的 D1。Cloudflare 还提供边缘网络、安全、运行监控及实际启用的资产存储服务。程序和数据库访问配置由 Nexa 管理，但托管设施由 Cloudflare 提供。

Cloudflare 的全球边缘可能在不同国家或地区处理请求。D1 的实际持久位置受创建配置和 Cloudflare 服务规则影响；区域提示不等于地域保证，Worker 请求处理位置也不等于数据库位置。**当前不承诺数据仅存储或处理于中国大陆。**具体托管规则可查阅 [Cloudflare D1 数据位置说明](https://developers.cloudflare.com/d1/configuration/data-location/)。

我们使用受限、采样的运行监控；关键接受、安全及业务事实另外记录。常规日志不应包含密码、恢复码明文、TOTP 密钥、OAuth 授权码、平台令牌或客户门户访问 URL。

### 7.2 身份、游戏和社区提供商

根据你的选择，GitHub、Google、Microsoft 参与登录身份处理；可选游戏关联还涉及 Microsoft / Xbox / Minecraft；爱发电参与你主动发起的 OAuth 关联。Bilibili 绑定尚未开放，计划仅使用你选择账号的公开资料核验。各提供商依据自己的政策处理其平台上的授权、资料和访问记录，不因 Nexa 的文档而受 Nexa 直接控制。

### 7.3 Paddle

当前用于 sandbox 订阅测试。实际通过 Paddle 销售 Nexa 自营产品时，Paddle 作为 Merchant of Record / 授权转售商处理订单、付款、税务、订阅和有关交易数据，并向 Nexa 提供必要状态。它不是第三方 Marketplace 分账或广告业务的默认支付工具。

### 7.4 邮件与支持

账户通知代码可在配置邮件服务后使用 Resend，传递收件邮箱、通知主题和必要内容。未配置时不会因此向 Resend 投递，账户页面仍显示操作结果；不要把邮件送达当作确认操作成功的唯一方式。支持邮箱和用户主动使用的第三方沟通渠道由对应服务处理通信；新增重要服务商会更新告知。

### 7.5 法定披露

在适用法律、有效执法请求、司法程序或处理重大安全事件所必需时，我们可能提供相应必要信息。不会因普通私人请求而任意披露账户资料、秘密凭据或内部核验证据。

## 8. 国际和跨境处理

Cloudflare 及第三方身份、游戏、付款服务可能在中国大陆境外处理数据，中国大陆用户的数据可能涉及跨境提供。接受服务条款、知悉本政策或自愿绑定第三方账号，不代表已经满足所有法定跨境条件。

在法律要求时，应提供接收方、目的、数据类型等必要告知，取得所需单独同意，采取必要保护措施并履行适用的评估、合同、认证或其他程序。本政策不声称已经完成某项未实际落实的程序；不能满足必要条件时，相应功能或地区应受限制。你可以通过隐私邮箱询问与你使用功能有关的处理路径。

## 9. 保存期限与清理

有效期表示凭据或挑战能够使用的时间，并不意味着到期瞬间删除所有数据库副本。定时清理按日执行，可能在下次任务才删除过期记录；必要调查或法定保存另有要求的记录会限制用途。

| 数据 | 当前一般规则 |
| --- | --- |
| 账户资料与登录身份 | 账户有效期间；解除身份关联删除相应映射，最终注销后删除或匿名化普通资料 |
| Console / Operations 会话 | 最长约 24 小时 / 1 小时；退出撤销，过期哈希由维护任务清理 |

## 10. 备份与删除

数据库恢复功能及受限运维快照可能在删除正常数据后暂时包含历史副本。Cloudflare 恢复窗口取决于实际账户计划和服务配置；人工运维快照与日常恢复功能分别管理，当前不宣称已经实现统一 30 天自动滚动任务。

备份限制访问，不用于恢复已经注销账户的日常服务；运维应按恢复目的复核、清除不再需要的副本。发生恢复时，需重新应用删除或注销标记，防止历史普通资料再次成为活动账户。依法暂不能删除的数据限制为必要存储、安全保护或对应法定义务用途。

## 11. 你的权利与操作入口

根据适用法律，你可以请求知悉处理情况、查阅和复制、更正和补充、删除、撤回基于同意的处理、注销账户、限制或异议、适用的数据可携带副本，以及对重要自动处理结果的解释或人工复核。相关权利可参阅 [《中华人民共和国个人信息保护法》](https://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)。

账户页“隐私与数据”提供数据导出、隐私请求和注销入口。导出包括账户资料、身份与关联、接受和告知记录、可提供的账户安全概况、游戏档案、等级与核验信息；不在普通导出中泄露密码、TOTP 密钥、恢复码或刷新令牌。需要进一步查阅、补充或更正时可发起隐私请求，或联系 `privacy@pcln.top`。

账户页可以撤销会话、解除允许解除的身份或社区关联、移除或替换验证方式及选择等级显示；主题偏好可在网页更改或通过清除浏览器存储删除。撤销可选授权不会影响此前已经依法开展的处理，可能停止依赖该授权的功能。必要交易或安全记录不能删除时，我们会说明理由与限制用途。

核实请求可能需要与风险相称的账户控制证明，不会无必要地要求敏感证件。对核验、铭牌或限制结果有疑问时，可提供新的事实申请复核；这不影响向有权机关寻求救济。

## 12. 账户注销

注销可在账户页“隐私与数据”或 `/account/delete` 提交，设有 7 天冷静期，期间可明确取消。冷静期届满后由维护任务最终执行，不表示服务器将在同一秒完成所有清理。

最终执行撤销会话，删除登录与社区映射、游戏档案和刷新令牌、MFA 因子、等级经验与活动、铭牌核验和显示选择，并删除或匿名化普通 Profile，关闭账户访问。注销标记与必要安全审计用于防止恢复和重复使用。仍需保存的交易、退款、投诉或法定记录与普通使用分开、限制用途；不会因注销而违法删除必要证据。

若实际资源或组织功能需要维持数据库完整性，可按适用服务规则处理归属或进入不可登录的保管状态；该安排不代表注销用户仍能经营账户，也不因本政策而提前启用尚未提供的功能。

## 13. 未成年人

用户应满足所在地法律及所选第三方、游戏服务的年龄规则。依法需要监护人同意时，应履行相应流程；中国大陆不满十四周岁儿童的个人信息适用特别保护要求。未提供法律要求的适当流程时，不能绕过限制自行启用相关账户功能。本政策不将一个固定全球年龄数字替代不同地区的强制要求。

## 14. 信息安全

我们使用 HTTPS、受限服务绑定、必要的会话隔离、OAuth 状态与一次性挑战、密码哈希、生产配置中的敏感秘密加密、证书校验、限流、访问控制和业务审计。托管或加密并不意味着运营者无法在必要授权流程中处理数据，也不能保证系统绝对无风险。

我们不要求你向支持人员发送第三方密码、Cookie、完整银行卡或两步验证秘密。发现泄露、篡改或丢失时，会按适用法律开展补救、记录、评估、报告和必要通知。

## 15. AI

当前不默认把私人内容发送给第三方通用 AI 模型用于审核、客服分析或训练。拟定 B站签名词库为固定版本的静态词组，运行时不调用 LLM 生成候选；草稿词库未通过人工审校不开放绑定。

如果未来启用 AI 处理，会先说明提供商、数据、目的、地区、保存与训练安排及适用选择。页面出现未来 AI 配额说明，不代表已授权向任何模型发送私人内容。
